# QA personas

All three are signed in to GitHub in Diorama.

## 1. Sam — solo developer
- **Setup:** one or two projects (a GitHub repo and a scratch repo). Runs one Claude agent at a time.
- **Habits:** starts a task, switches to other work, glances back every 10–20 minutes. Uses the mouse, rarely the keyboard.
- **Wants to know:** "Is it done? Does it need me?"
- **In a session:**
  1. Opens Diorama and reads Home to see whether anything is waiting.
  2. Starts a small task from Home's **New task**.
  3. Comes back later and answers a question the agent asked.
  4. Opens the finished work from **Review** and checks it's cleared from Home.
  5. Peeks at the kitchen to see what the chef is doing.

## 2. Priya — power user
- **Setup:** many projects: GitHub repos, a local-only git repo and a plain folder. Runs 8–10 agents at once across Claude and Codex.
- **Habits:** lives on Home. Keyboard first (←/→, ↑/↓). Watches tokens and weekly limits. Hates cards jumping around.
- **Wants to know:** what's ranked first and why, how fast the page updates, and what she's spending.
- **In a session:**
  1. Starts 8–10 tiny tasks across three projects, both providers.
  2. Flips through Needs you and Active with the arrow keys, including fast repeated presses.
  3. Answers two agents that ask at the same time, straight from Home.
  4. Watches ranking change as tasks finish, and reads tokens and limits.
  5. Searches Recent projects, then resizes the window down to check the layout holds.

## 3. Noor — newcomer
- **Setup:** just installed Diorama and added one project. Has never started an agent and doesn't know what "the kitchen" is.
- **Habits:** reads every label, clicks the most prominent button, gets lost easily.
- **Wants to know:** "What do I do first? What is this page telling me?"
- **In a session:**
  1. Opens Home and reads the empty states.
  2. Uses **Add project** to add a folder.
  3. Starts a first task from the project's card.
  4. Clicks **Open kitchen** and tries to work out what the chefs mean.
  5. Comes back to Home and works out where the task went.
