## Kitchen

- Agents work as chefs in a kitchen: each one walks to the stove, tasting station, pantry or prep area based on the tools it actually calls, and waits at the bell when it has a question for you.
- Name tags carry a four-word summary of the task and honest progress from the agent's own task list.
- Select a chef to open the command bar: the task, assignee and model, cost, branch, and every changed file with its line counts, beside a live activity feed.
- A restaurant scene, kitchen sounds, and a live tools bar showing the connectors and skills chefs are using.

## Agents and review

- An agent panel grouped Needs you, In progress, Done and Idle, plus a task board.
- Review request and review changes windows; a turn that ends with a question is marked as needing you.
- GitHub: connect an account, open and update pull requests from the review window, and follow checks and merge readiness.
