## Live office preview

- Navigate from a compact project portfolio to a shared 3D office, individual agents, and their work screens.
- Home shows working/attention counts and all-time reported token usage, including externally started Codex and Claude sessions.
- Furnished offices include capybara agents, cream-and-walnut walls, wood floors, and a wind-blown meadow.
- Display-linked rendering requests up to 120 Hz. Grass meshes are generated in the background; furniture detail and observation caching reduce repeated work.
- Local Apple Silicon captures at 3024 × 1898 met the 60 FPS frame-interval target with 16 and 64 animated agents. The 95th-percentile intervals were 9.70 ms and 11.73 ms, with none above 33 ms in the captures. This is not a universal 120 FPS guarantee.

This is a preview for testing. Automatic graphics-quality adjustment remains disabled. Usage totals can be partial when providers do not report complete history; stale observations stay labeled. Navigation does not start agent turns. Fresh-Mac authentication, other displays, and larger real-world projects still need testing.
