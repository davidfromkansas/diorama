# Live office agent roster

The Agents control toggles a light 300-point panel inside the office. Its source is the same SpatialWorld / WorkspaceAgent projection used by avatars, including existing provider restrictions and persistent names. It includes every reported agent for the current project; completed/stopped/failed agents live in collapsible Recent even after their desks are no longer retained. Branches are reported only for matching known workspaces; missing metadata is explicit. Selecting a row opens the existing conversation panel with expanded focus, preserving the office camera.

Recency uses meaningful provider activity/status signatures and provider timestamps, with first receipt time for untimestamped evidence. Repeated freshness observations do not advance recency. Bounded replay signatures and out-of-order checks preserve newer activity. Publication is coalesced to four times per second at most; the existing observation schedule remains authoritative. There is no new polling loop.

Rows use NSTableView virtualization with fixed heights, stable identities, and updates to changed visible cells. Reordering retains the first visible identity and its pixel offset. Keyboard selection follows its identity; pointer tracking defers publication until release. Changes above the viewport expose New activity. Collapse/Recent/scroll state stays in memory per project. Narrow offices use a roster overlay, automatically collapsed when opening a conversation. Reduced Motion and inactive/hidden views disable decorative motion. Highlights and working-indicator changes occur only on reported updates, without perpetual animation.

Verification uses deterministic recency, replay, terminal-state, routing, burst, and native anchor tests. The opt-in DIORAMA_ROSTER_BENCHMARK=1 test exercises a visible native window with 64 working avatars, meadow wind, scrolling, and bursts of eight agent updates every 100 ms. It writes measured frame intervals to /tmp/diorama-roster-performance.txt. Fixture execution does not contact coding providers.

## Verification on 2026-10-02

- 37 targeted roster, observation, avatar, spatial navigation, and scrolling regressions passed. A separate broader run passed 29 naming, observation, navigation, and paging tests (some coverage overlaps).
- Inspected the installed panel using real saved observations: Recent expands, names and workspace details render, selecting Ada opens Ada’s existing conversation, and the narrow layout collapses the roster. No paid turns were started.
- The first opt-in test-runner benchmark was invalid: macOS reported the window occluded and delivered zero rendered frames. Its 122 coalesced publications are not FPS evidence.
- Added **File → Benchmark live agent roster** to the development app only. It opens a fixture window in the same app, captures 64 working avatars, wind, scroll movement, and bursts, and writes `/tmp/diorama-roster-native-64.txt`. Normal production data remains untouched.
- After unlocking, the visible app-hosted 64-agent capture passed: requested 120 FPS, scene backing resolution 1694 × 1560, 9,750 rendered-frame intervals, median 8.327 ms, p95 8.703 ms, zero intervals above 33 ms, and meadow cache 5,179,296 bytes. Cold setup plus warmup was 8.086 seconds. The fixture included roster scrolling, eight activity changes per burst, working avatars, and wind. Closed the diagnostic window afterward and restored the normal office without starting provider turns or restarting the app.
- These are SceneKit rendered-frame callback timings, not GPU presentation or input-latency measurements. The nominal 30-second harness uses 300 asynchronous sleeps and ran longer than 30 seconds (the frame count is approximately 81 seconds at 120 Hz); it must not be reported as a precisely timed 30-second capture. This run meets the frame-interval threshold but does not establish a universal performance guarantee or precise burst-delivery cadence under load.
- Full VoiceOver narration and the native pointer-under-burst visual check remain unverified. Exact native scroll anchors, selected-row identity, pointer publication deferral, and reduced-animation paths are covered structurally or by deterministic tests.
