# Kitchen props

Decorative models for the kitchen scene, optimized with the food pipeline
(`assets/food/optimize_food.py`: decimated, textures resized, centred with the base at 0 and the
widest side 1.0). Originals live in `source/`; run `assets/props/build.sh [id ...]` to rebuild
`Sources/DioramaApp/Resources/KitchenProps/`.
